# R57 — Landing pages for the career-document tools

## Evidence (first-hand, 2026-08-29, ~/audit-r1/shots-r57/)

- Rezi (`rezi-tools-full.png`): a `/tools` directory markets every capability as its own
  destination, and the site footer's "AI Career Tools" column links standalone landing
  pages (Cover Letter Generator, Interview Practice, Resignation Letter Writer, …). Each
  tool is discoverable from search engines without ever opening the app.
- RezUp: the cover letter generator, interview prep (brief + practice with AI feedback)
  and resignation letter writer all exist and work in production — but only *inside*
  `/builder`. There is no page on the site that tells a searcher these tools exist. `/ai/`
  mentions "cover letters & interview prep" in one section; nothing is individually
  linkable, and none of it appears in the sitemap or `llms.txt`.

Gap class: 落地页/SEO P2 — three shipped, differentiating tools are invisible to organic
search and unlinked from the site's information architecture.

## Decision

Add three static landing pages, generated by `scripts/build-seo.mjs` like every other
static page (zero JS, shared header/nav/footer, canonical + OG + breadcrumb JSON-LD):

- `/cover-letter-generator/` — AI cover letter from your resume + the specific posting,
  letterhead PDF/DOCX export. CTA deep-links `/builder?doc=cover` (R33/R38 deep link
  opens the tool directly).
- `/interview-prep/` — interview brief (likely questions, STAR stories from your real
  experience, gaps to prepare), AI-suggested practice questions and answer feedback.
  CTA → `/builder?doc=interview`.
- `/resignation-letter-generator/` — professional resignation letter with letterhead
  export. CTA → `/builder?doc=resignation`.

Each page: hero + honest one-paragraph pitch, "How it works" 3 steps, 3–4 FAQ entries
(free during beta / grounded-in-your-resume honesty / browser-local storage / export
formats). Wire into the IA: nav Resources dropdown (`RESOURCE_LINKS`), the footer
Resources column (static `FOOTER_COLUMNS` + React `Layout.tsx` mirror), `sitemap.xml`
and `llms.txt` Core tools.

Deliberately not copied: Rezi's full `/tools` mega-directory and tools we don't have
(AI headline generator, LinkedIn summary tool, video interview simulator) — no page may
market a capability that doesn't exist in the product.

## Verification

Local lint / `npx tsc -b` / build; deploy; production QA at 1440px and 375px on all three
pages (content renders without JS, CTAs deep-link into the builder and open the right
tool, no horizontal overflow, console clean); footer/nav links resolve.
