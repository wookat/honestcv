# Kickresume 实测笔记（R1，父会话亲测 2026-08-05）

- 注册：邮箱注册成功但必须邮箱激活；mail.tm 临时邮箱收不到激活邮件（等待 3+ 分钟，收件箱 0 封），未激活无法登录（"email and password did not match"）。→ 登录后编辑器/AI writer 未能体验，如实标注。
- 定价（截图 ss_d48c6a89）：订阅制，20% off 倒计时条（urgency 暗黑模式）。Yearly $6.40/mo（一次付 $76.80）、Quarterly $14.40/mo（$43.20/3mo，"Most popular" 预选样式）、Monthly $19.20/mo。免费层：基本模板数量受限（官网 FAQ 称 4 free templates）。
- 模板（ss_aa708c54）：40+ 模板，大量双栏/带头像/装饰图形（Doodle/Nature/Bubbles 等），视觉华丽但多数非 ATS 单栏；模板列表页每个模板配 SEO 文案。
- ATS Checker（ss_e1a3dc32 → ss_cb5b8a95）：宣传 Design/Structure/Content 三维评分（85/100 示例），但点击 Upload Your Resume 直接跳转注册页 —— 免费工具其实是注册墙引流。对比：RezUp /ats-checker 完全无需账号。
- 观感：营销页打磨极好（Trustpilot 4.6、名企 logo、hired-with 轮播），信任要素充足。
