# 对标复刻批次1·A阶段 —— 《逐屏对照表》与复刻改造清单

主标尺 Rezi ×我方 RezUp（cv.zalize.com）。截图证据见 `screens/`，设计参数见 `gazetteer.md` / `design-params.json`。
每屏按六项对照：①布局骨架 ②间距节奏 ③字阶 ④色彩 ⑤组件形态 ⑥交互反馈。
改造项编号 P-xx，可直接按屏派发给前端；[P0]=本批必做，[P1]=下批，[P2]=择机。

---

## 屏1 · Landing（R01 vs Z01）

| 维度 | Rezi | RezUp 现状 | 差异结论 |
|------|------|-----------|---------|
| ①布局骨架 | hero 只留「眉题+大标题+单 CTA」，紧跟**满屏产品 mock**；此后每屏一个主张，白/黑/蓝大区块交替，含数据带、Forbes 权威引言、logo 信任带 | hero 文案+双 CTA 后直接进入 3 步卡与 6 卖点卡；无产品视觉、无信任带、无数据带；定价/FAQ 同页压缩 | **最大差距：首屏无产品可视物、全页无信任背书层** |
| ②间距节奏 | 章节间大留白（>120px 观感），一屏一事，滚动有呼吸 | 段间 32–64px，卡片密排，一屏多事 | 节奏偏「文档」，缺「叙事」 |
| ③字阶 | H1 55.5px/1.15/500（专用展示字体 PP Neue Montreal），正文 17.6px/#545454 | H1 48px/1.0/700（Sora），正文 16px/纯深色 | 我方标题字重过重、行高过紧；正文对比度过高显生硬 |
| ④色彩 | #FAFAFA 底 + 纯黑情绪区 + 品牌蓝 CTA 带，三色分区制造节奏 | 全页单一近白底，蓝紫仅用于按钮 | 无色彩分区，长页扁平 |
| ⑤组件形态 | 编辑器 mock、评分环、模板横向滑轨、评价三列卡、FAQ 手风琴 | 静态图标卡、模板缩略墙（小图）、FAQ 纯文本 | 缺产品 mock 与评分环两大「招牌组件」 |
| ⑥交互反馈 | hover 0.2–0.3s easeOutQuart；滑轨可拖动；FAQ 展开动画 | 0.15s 默认曲线 + hero rise-in | 手感可，但缺横滑/手风琴动效 |

**改造清单**
- [P0] P-01 hero 下新增「产品 mock 区」：真实 /builder 截图式组合（左编辑列+右预览+ATS 评分环浮层），替代纯文字首屏。
- [P0] P-02 新增信任带：beta 用户数/导出份数/ATS 通过率等真实数据带（诚实原则：只放真数据，无则先放「honest by design」主张带）。
- [P0] P-03 章节垂直间距升档：py-16 → py-24/32，一屏一主张；定价与 FAQ 之间插入色彩分区（深色情绪区讲「never charge monthly」故事，替代现对比表的纯表格呈现）。
- [P1] P-04 字阶调整：H1 行高 1.0→1.1，字重 700→600；正文色降为 gray-600 级；引入 52–56px 展示档（仅 Landing hero）。
- [P1] P-05 FAQ 改为手风琴组件（Radix Accordion，已有依赖），带 0.2s 展开动画。
- [P2] P-06 模板墙加横向滑轨交互（scroll-snap），大图预览化。

## 屏2 · 定价（R02 vs Z01 定价段）

| 维度 | Rezi | RezUp 现状 | 差异结论 |
|------|------|-----------|---------|
| ①骨架 | 独立 /pricing 页：三卡 + 全功能对比长表 + FAQ | Landing 内嵌双卡 + 一个「为什么不按月收费」对比表 | 我方无独立定价页（SEO+转化入口缺失） |
| ②间距 | 卡片大 padding，推荐卡放大 105% 抬升 | 双卡等大，Career Bundle 仅描边高亮 | 推荐卡强调不足 |
| ③字阶 | 价格数字超大（~48px）+ 周期小字 | $19.99 约 30px | 价格锚点视觉弱 |
| ④色彩 | 推荐卡深色底反白，贯穿对比表的浅蓝高亮列 | 白卡蓝描边 | 高亮语言弱一档 |
| ⑤组件 | 逐行勾选清单 + 分组对比长表 | 勾选清单（已有）+ 对比表（已有，形式不同） | 结构已对齐 70% |
| ⑥交互 | 卡 hover 抬升、表格粘性表头 | 无 | 细节缺失 |
| 定价锚点 | AI 写作/Keyword Targeting/无限下载压在 $29 订阅后 | 我方 $9.99/$19.99 一次性买断 | **差异化优势，保留并放大「one-time」对比叙事** |

**改造清单**
- [P0] P-07 Career Bundle 卡升级为「深色底反白 + Best value 徽章 + 轻微放大」的推荐卡形态；价格数字升到 44–48px。
- [P1] P-08 拆独立 /pricing/ 静态页（prerender 管线内新增），含双卡 + 功能对比表 + 定价 FAQ，Landing 定价段保留精简版。
- [P2] P-09 对比表推荐列加浅色底贯穿高亮。

## 屏3 · 编辑器（Rezi 编辑器【待域名邮箱注册后补】vs Z02）

依据：R01/R04 内嵌编辑器 mock 与 R07 Dashboard 渲染图（像素级参数待注册后补齐）。

| 维度 | Rezi（据公开 mock） | RezUp 现状 | 差异结论 |
|------|------|-----------|---------|
| ①骨架 | 左侧**分区图标导航栏**（深紫窄栏）+ 中央文档画布 + 右侧评分/AI 面板三栏 | 左表单列 + 右预览列双栏，模板/设计控件横置预览顶端 | 我方无分区快速导航；设计控件占预览头部空间 |
| ②间距 | 文档画布居中悬浮、四周深色衬底，纸感强 | 预览白卡贴边，无纸感衬底 | 预览沉浸感弱 |
| ③字阶 | 面板标题小、文档为主角 | 表单标签/输入字阶合理 | 差距小 |
| ④色彩 | 深色工具栏 + 白纸 + 评分绿环点缀 | 全浅色 | 层次略平 |
| ⑤组件 | 评分环（92 大数字绿环）、Keyword Targeting 勾选列表 | ATS match score 红色大数字 + 展开式解释（已有，形态不同） | 评分呈现方式：环形可视化 vs 裸数字 |
| ⑥交互 | AI 面板浮层、逐关键词绿勾状态 | Tailor 对话框逐行建议（已有） | 能力对齐，呈现待升级 |

**改造清单**
- [P0] P-10 ATS 分数改为**环形进度环组件**（SVG ring，0–100 着色分档红/黄/绿），放大数字，替换现纯文本红数字。
- [P1] P-11 预览列加「纸张」处理：文档卡投影 + 中性灰衬底 + 居中悬浮，设计控件（模板/色板/字号）收进预览上方工具条或抽屉。
- [P1] P-12 关键词匹配结果升级为 Rezi 式逐关键词状态列表（绿勾/灰点，JD 已贴时），替换纯文字缺失列表。
- [P2] P-13 左侧加分区锚点图标栏（Contact/Summary/Experience…点击滚动），桌面≥lg 显示。

## 屏4 · 模板库（R03 vs Z04）

| 维度 | Rezi | RezUp 现状 | 差异结论 |
|------|------|-----------|---------|
| ①骨架 | 按**用途策展**分组（Recruiter favorites/Tech & startup…），组内大图预览+推荐语 | 按样式分组（Banded/Serif/Minimal/Modern sans），小缩略图+链接列表 | 策展叙事 vs 目录清单 |
| ②间距 | 每组一屏级空间，模板图接近实际纸张比例大小 | 行式列表，缩略图 ~90px 宽 | 预览可读性差距大 |
| ③④ | 55px 组标题、白底黑字 | 18px 组标题 | 层级弱 |
| ⑤组件 | 大图卡 + hover 用模板 CTA + 评分条 | 缩略图 + 文字链 | 缺卡片化 |
| ⑥交互 | hover 显示 CTA | 无 hover 反馈（hover 媒体查询坑见 skill） | 缺 |

**改造清单**
- [P0] P-14 /templates/ 枢纽改卡片网格：每模板 240px 级大预览图 + 名称 + 一句话适用场景 + 「Use this template」直达 /builder?template=x。
- [P1] P-15 增加「Recruiter picks / Tech roles / High-density」策展分组视角（保留样式分组作次级筛选）。

## 屏5 · AI 功能展示（R04 vs 无对应页）

- Rezi 用独立 /ai-resume-builder 页逐屏卖 AI 能力（每能力=一屏截图+主张）；我方 AI 能力（Tailor/rewrite/cover letter/interview prep）只散在 Landing 卖点卡与 builder 内，无集中展示页。
- **改造清单**：[P1] P-16 新增 /ai/ 静态页（prerender），复用 builder 真实截图逐屏展示 Tailor→评分→改写→求职信四能力；Landing 卖点卡各卡链入对应锚点。

## 屏7 · 示例库（R06 vs Z05）

- 结构已对齐（分组 + 角色链接 + 一句话摘要）；差异：Rezi 每卡带**简历首页缩略图**，我方纯文字列表；Rezi 有角色搜索框。
- **改造清单**：[P1] P-19 /examples/ 每角色加缩略预览图（可由模板渲染管线生成静态 PNG）；[P2] P-20 加客户端过滤搜索框。

## 屏8 · 注册/空态（R07 vs Z02 空态）

- Rezi 强制注册（OAuth 优先），注册页右侧即产品预览；我方**无账号体系**（本地存储，卖点「No account needed」）——差异化保留，不复刻注册墙。
- 我方 builder 空态已有：示例载入 + 角色 picker + Getting started 清单，优于 Rezi 公开可见空态。**无改造项，保持。**
